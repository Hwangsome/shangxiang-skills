# 商详裁剪

把一个文件夹里的商详长图，批量裁成每张都是“一个完整卖点”的分图。每张商详图在输出目录下得到一个同名子目录，分图按 `_01`、`_02`… 编号，按顺序拼回去与原图逐像素一致。

## 为什么这样切

商详图是设计师一块块拼出来的：标题 → 说明 → 配图。随手按固定高度切，会把一行字腰斩、把照片劈成两半，顾客看着别扭。所以切点只放在两类地方：

1. **纯色底区域里的空白间隙**——区域内最宽的间隙最好；很窄的间隙多半只是行距，尽量不切。
2. **两块照片/内容之间贯穿整行的水平分界**。

另外，大字标题属于它**下面**的内容：间隙上方紧挨着标题时不切，下方紧挨着标题时优先切。在满足这些条件的切点里，再用动态规划挑一组让每段接近 3:4 竖图（高 ≈ 1.33 × 宽）的方案；单个版块很长时最多到 2.4 × 宽，再长才允许在内容里切。

细节和参数都在 `scripts/cut_v2.py` 顶部的常量里，一般不需要改。

## 怎么做

1. 确认源目录（放商详长图，支持 jpg/png）和输出目录。用户没给输出目录时，在源目录旁边建一个 `<源目录名>_裁剪`。
2. 运行批量脚本（需要 `numpy`、`Pillow`）：

   ```bash
   python scripts/crop_batch.py <源目录> <输出目录> [进程数，默认 4]
   ```

   已经有分图的子目录会跳过，所以中断后可以直接重跑。结果追加写入 `<输出目录>/裁剪清单.csv`（原图尺寸、分图数、切点位置）。
3. 看终端最后一行“完成 N 张，失败 M 张”。有失败的，把文件名和错误告诉用户。
4. **抽查**：挑 2–3 个商品，把分图并排拼成一张预览图给用户看（或直接打开分图），重点检查有没有文字被切断、标题和配图有没有被分开。

## 交给下一步

- 要上传到电商平台：裁剪出来的分图按 3:4 为目标，但个别长版块可能高于“宽 × 2”。上传前用 `shangxiang-upload-check` 检查并修复。
- 要翻译：分图目录直接作为 `shangxiang-translate-ms` 的输入。

## 发现切得不好时

不要改一张图就手工修一张。先找出是哪一类版式出的问题（比如“浅灰底上的细线标题”），调整 `cut_v2.py` 的规则或参数，再**只重跑受影响的商品**：删掉这些商品的输出子目录，重新运行 `crop_batch.py` 即可（其它商品会被跳过）。
