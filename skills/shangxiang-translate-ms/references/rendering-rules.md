# 擦字与排版规则

本文件说明 `scripts/render_step.py` 的行为，内容来自实际批量处理 305 个商品时整理的规则。

## 处理规则

- 只替换含中文的行；英文、型号、数字原样保留，擦字时也只保护它们的笔画，不会被抹掉。
- 擦字：先把所有笔画按连通块分给各行（中文和紧贴的英文互不干扰，粘连的按最细处切开），连同抗锯齿边缘一起擦干净。
  近似纯色底直接填底色；平滑的渐变或半透明底用平滑插值；只有照片纹理底才用 LaMa（避免凭空生成斑点）。
- 输出 JPG 质量 95、4:4:4 采样，文字落在整数像素上，彩色小字边缘不发糊。
- 颜色取原文字笔画的颜色；字体用微软雅黑（常规 / 粗体 / 细体），粗细按原笔画宽度与字高的比例判断（金色、浅色字按字色与底色的中点取笔画，小字阈值放宽；同排并列项按多数统一粗细）。
- 字号对齐原字高。马来文较长时，按以下顺序处理：先往空白背景方向加宽 → 再折行（只用下方的空白）→ 最后缩小，最小到原来的 60%（且 ≥12px）。
- 文字压在色块标签上时（含渐变色的药丸形标签），按行在色块内插值擦字；先略缩小（≥82%），仍放不下才把色块从中间向两边对称拉长。
- 往旁边加宽时，照片/大理石等纹理底按纹理起伏判断“有没有挡住”，纹理本身不算障碍；同一排的两段各占中间空隙的一半，不会互相压住。
- 对齐：项目符号列表靠左；上下两行中心对齐且两侧都有空的按居中；贴左页边的按靠左，其余默认靠左。
- 单行文字放不下时先略缩小保持一行，再考虑折行。
- 同一行、同一列（可传递，如 3×2 图标格）里同样式的并列项统一成最小字号。
- 行首被 OCR 认成“）”的色点/圆圈图标不擦、不翻；弧形排列的字按字宽定字号。
- 行首的彩色圆圈序号（①②…）被 OCR 连进文字时（如“1将安装面…”），按颜色和填充判断出是图标，保留圆圈、译文去掉数字；靠左排的新文字从原中文笔画的起点开始，和图标的间距保持原样。
- 空白一直通到图边时也留出页边距，文字不贴边。
- 大标题旁边有小字说明时，标题优先占用中间的空隙，小字不往标题那边扩；字高相近的并列项才平分空隙。
- 一叠标题放不下时先整体缩小（最小 60%）保持原行数，实在放不下才折行。
- 同一行 ≥3 段字高相近、等间距的文字（图标格的标签行）按居中排。
- 段落里有彩色高亮的行也归为同一叠（统一字号，各行保留自己的颜色和粗细）；竖排的几个色块标签各自单独排。
- 色块一端连着 ✓、× 等图标时不拉长色块，只缩小字；拉长色块只动色块所在的行，周围的渐变底不跟着平移。
- 竖排的中文（框高 > 2 倍框宽）：马来文顺时针转 90° 从上往下写，字号按竖栏宽度，长度放不下就缩小；竖的胶囊标签按胶囊长度算；并排的几条统一字号。
- 表格的一列（每行旁边都有对应的值）只缩小不折行，保证行和值对齐；并列项统一字号时，个别特别长的不拖累整组。
- 和标题重叠的装饰字（如压在标题下面的花体英文）不算障碍，也不算上下邻居；和中文同色、连在装饰字上的笔画照样擦掉。
- 浅色渐变底只有几乎没有起伏时才直接填色，否则平滑修补（避免一块块补丁）。
- 一句话被拆成几行的会合成一段重新折行；同一列的并列项（如编号注意事项）统一字号，依次往下排。

## 已知不足

- 很挤的小标签（如环形图标旁的“安装方便 / Convenient”）空间太小，马来文只能缩到 12px 左右。
- 同一行里“粗体标签 + 常规内容”（如“品牌 / XXX”）目前统一按一种粗细写。
- 本机 paddlepaddle-gpu 与 torch 的 CUDA 库冲突，所以 OCR 用 RapidOCR（显卡版用 onnxruntime-gpu，建议放在单独的虚拟环境里）。
- 色块上的白色小字、和英文小字挨得很近的折行副标题，个别分图仍需人工微调。
